# Bundled fonts

Fredoka and Nunito are variable fonts from the Google Fonts repository, bundled so
production builds do not depend on the Google Fonts download service. Both retain
their original SIL Open Font License in the adjacent OFL files.

- Fredoka: https://github.com/google/fonts/tree/main/ofl/fredoka
- Nunito: https://github.com/google/fonts/tree/main/ofl/nunito

Downloaded October 12, 2026. The layout uses `next/font/local`, retaining the
existing font CSS variables and swap display behavior. Update the font and its
license together when refreshing these assets.
